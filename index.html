Tippe auf eine Stunde zum Bearbeiten. Wähle oben ein Fach und tippe auf eine Stunde, um es schnell einzutragen. Halte eine belegte Stunde gedrückt und ziehe sie auf eine andere, um sie zu verschieben oder zu tauschen.

Ziehe ein Fach aus der Fächerliste in ein Feld oder verschiebe belegte Felder per Drag-and-drop. Beim Ablegen auf einem belegten Feld wird dessen Inhalt ersetzt; beim Verschieben werden zwei belegte Felder getauscht. Auf Touchgeräten kannst du ebenfalls ziehen. Klicke auf ein Feld, um es direkt zu bearbeiten. „Speichern“ sichert den Plan in diesem Browser. Über „JSON sichern“ kannst du ihn auf andere Geräte übertragen.

Alle Daten bleiben lokal auf deinem Gerät. Kein Benutzerkonto, keine Cloud.
